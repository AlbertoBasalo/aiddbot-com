Plain markdown. Any agent. No package left behind — the skills travel with the repo.

## Install

Node.js 18 or later, Git, and one agent: Claude Code, Codex, Cursor, or GitHub Copilot.

From the root of your repository, run `npx github:AIDDbot/AIDDbot init`.

That copies the skills, adds the agent profiles, and commits them. Files you already have stay untouched. In Codex, start each command with `$`.

## Architect

Open the agent in that folder and map the system: `/architect-initial-foundation`.

Legacy code is scanned. A new system is scaffolded. You approve the foundation and the rules.

## Build

Name the change before anyone codes: `/architect-requested-spec riders can rate a trip from 1 to 5 stars`.

You approve the spec. Nothing is built yet.

Then construct that change: `/build-requested-spec`.

The agents write the code, prove it, and ship a version.

## Craft

Keep the quality maintainable: `/craft-lasting-quality`.

Debt becomes the next repair, so the system lasts.
